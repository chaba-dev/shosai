# Contents navigation and reference previews

Captured on 2026-11-03 from the native Flutter Linux application, using the real
Dart EPUB/PDF engines, application core and bundled fonts. The documents are
generated by [`reference_documents.dart`](../../../test/support/reference_documents.dart).
No physical devices were used: desktop, tablet and phone name the 1200, 800 and

The screenshots are 2× repaint-boundary captures from
[`reference_peek_test.dart`](../../../integration_test/reference_peek_test.dart).
`contents-*.png` shows the target after choosing Contents, with the panel closed,
no peek and a Back pill. `peek-*.png` shows an in-text footnote still previewing
over the source page, with regular-weight body text. The recording uses actual
X11 pointer movement and clicks, including Contents → target → Back and in-text
footnote → peek. It is not a generated animation. It was captured from a normal
native app entrypoint opening the same generated EPUB; the automated integration
test also checks the peek → Go to → Back flow.

## Reproduce

Run from the Nix development shell with an X11 display and Mesa available:

```sh
GDK_BACKEND=x11 \
__EGL_VENDOR_LIBRARY_FILENAMES="$SHOSAI_TEST_EGL_VENDOR" \
SHOSAI_REFERENCE_ARTIFACTS=/tmp/shosai-reference \
flutter test --no-pub -d linux integration_test/reference_peek_test.dart
```

For native pointer input, set `SHOSAI_REFERENCE_POINTER=1` and run the desktop
EPUB case with `--plain-name 'epub peek, dismiss, jump and Back at width 1200.0'`.
Record the X11 display with the pointer visible. The automated test asserts the
source/destination pages, peek absence/presence, panel closure and Back behavior;
the screenshots and recording show the exercised UI.

commits do not add binary media to the main branch.
